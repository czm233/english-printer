## AI 助手

设置 → 大模型：填写 API URL、API Key、模型 ID 并保存，再点击底部中央圆形按钮进入聊天。

- 协议为 [Anthropic Messages](https://platform.claude.com/docs/en/api/messages/create)，不是 OpenAI Chat Completions。请求使用 `x-api-key` 和 `anthropic-version: 2023-06-01`。
- API URL 可以填写根地址、以 `/v1` 结尾的地址，或完整 `/v1/messages` 地址。根地址自动补 `/v1/messages`；使用自己的网关时必须兼容该协议。模型 ID 按服务商实际支持项填写。
- 外部服务要求 HTTPS；本机模拟接口支持 HTTP。URL 不接受账号、密码、查询参数或片段，也不自动跟随重定向。
- 支持流式多轮聊天、停止、失败重试、新对话；首段返回前显示“正在回复…”，收到文本增量后逐段显示。每次最多生成 2048 tokens，请求超时 120 秒。使用 [Anthropic SSE 事件协议](https://platform.claude.com/docs/en/build-with-claude/streaming)，忽略思考与签名；白名单打印工具独立解析为确认卡片，不伪造打字效果；流未正常结束时显示中断错误。
- Markdown 支持表格、标题、强调、列表、引用、代码及链接。使用本地固定版本 Marked 18.1.0 与 DOMPurify 3.4.16；仅允许安全排版标签，阻止脚本、图片、事件及不安全链接。宽表格可左右滑动，整页不横向滚动，阅读时不会强制回到底部。
- 停止或中断时保留已经收到的文字；重试会替换未完成的回复，不重复添加用户消息。只有完整回复进入后续模型上下文；未完成时可重试，也可直接发送下一句；上下文标注上一条未完成。
- 聊天记录保存到本机，“新对话”开启新上下文，右上角时钟可恢复或删除历史；不按时间或 10 条上限自动清理。最多 20 轮对话，随后需新建对话。
- API Key 不放在浏览器 localStorage。配置以本机 JSON 文件保存在 `.local/model-config.json`，文件权限 0600，已加入 `.gitignore`；没有加密，不是钥匙串存储。静态服务仅暴露 `web/`，读取配置的接口不会返回 Key。
- 已保存 Key 后输入框留空会保留它。更换 API URL 时必须重新填写 Key，避免将旧 Key 自动发送到其他地址。模型可单独更换。
- 消息和上下文会发送给你配置的模型服务。现有打印页的 MyMemory 翻译暂时独立，不改由聊天模型处理。

## 实物打印

网页已接入实际设备。打印机开机并断开手机微打后，在“设置 → 标签”点“连接”；回到“打印”页输入中文，翻译与音标完成后点“打印”，每次打印一张。未连接时点打印会先尝试连接。

自选英文时，点主打印按钮上方的“自定义打印”，输入英文（例如 Fridge），停止输入后自动生成美式宽式音标，再点弹窗里的“打印”。纸面仍为上英文、下音标；底部左侧打印、右侧取消，清空位于英文与音标标题右侧。音标使用现有本地词典，大小写不影响查询，词组仍只加一对外层斜杠；未知词、部分缺词、过长内容会阻止打印，无需手敲音标。打印成功后主页面同步显示自选词。

- 设置中的字号、边距、边框会同步到实际标签；编辑设置里的英文、音标也会同步主打印页。超出标签范围时停止打印，不裁掉文字后继续发送。
- 模板固定 30×12mm、上下两行、203dpi、90°、间隔纸 3mm、偏移 0；浓度与速度沿用设备默认。
- Node 服务通过常驻 Swift CoreBluetooth 子进程保持连接，断开按钮实际释放连接；服务结束时蓝牙子进程自动退出。当前仍由 Mac 控制蓝牙，不是浏览器直接连接，也未移植为 iOS App。
- 检查真实设备状态后才下发，缺纸、开盖、忙碌等会显示错误。打印期间防止重复点击，同一请求 ID 的持久化记录避免重复发送；失败不自动补打。
- 页面“已打印 1 张”表示已收到设备完成状态；只能确认写入时显示“已发送 1 张，请查看出纸”。遇到“结果未确认”先看打印机是否已出纸，再决定是否重试。
- `.local/bin/` 存放自动编译的 Swift 程序；`.local/print-jobs/` 保存请求记录和最近一张栅格图，仅供本机诊断，已忽略 Git，不通过静态服务暴露。不要在有任务处理中时清理这些文件。
- 默认仅连接已验证 P0 的本机蓝牙 UUID；其他设备需设置 `P0_DEVICE_ID`，并重新进行设备验证。

## 对话中的打印 Agent（2026-10-11）

AI 根据讨论选定单词或词组后，通过 Anthropic `print_label` 工具提供英文与美式音标。App 在完整响应结束后校验工具与参数，生成确认卡片；点击前不操作打印机。卡片确认一次即锁定，成功显示实际回执，失败或结果不明不自动重试。需要再打印时继续对话生成新卡片。旧卡片内容不随换词修改。

工具定义和提示词共用 `web/agent-config.json`，Mac 服务与 iOS 均加载它。工具参数独立于 Markdown，每个工具仅允许英文和 IPA 两个字段，可在同一轮返回多个工具；下一轮按 Anthropic `tool_use` / `tool_result` 传递卡片状态。兼容服务必须支持工具调用和流式工具参数；只支持普通文本的模型不会产生可确认卡片。

对话持久保存在本机，关闭 App / 刷新后恢复；已确认卡片跨重启保持禁用，底层设备通道另有持久任务防重。确认时沿用当前标签设置；超长 AI 词组按完整单词拆成多张卡片，单词仍超长时拦截，不裁剪、不自动缩字。模型生成音标只校验字符和排版格式，不等同于词典校对。

协议参考：[工具调用及工具结果](https://platform.claude.com/docs/en/agents-and-tools/tool-use/handle-tool-calls)、[流式工具参数](https://platform.claude.com/docs/en/agents-and-tools/tool-use/fine-grained-tool-streaming)。
