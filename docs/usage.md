# 使用与配置

[返回项目首页](../README.md) · [开发与排障](development.md) · [iOS 构建](../ios/README.md)

## 先体验界面

在仓库根目录使用 Node.js 22+ 启动：

```sh
./scripts/preview.sh
```

打开 [http://127.0.0.1:10290/](http://127.0.0.1:10290/)，输入“冰箱”，即可体验内置候选、音标和朗读入口，无需翻译或模型凭证。按 `Ctrl+C` 停止前台服务。启动前检查端口归属，已有本工作区服务时直接复用；长期运行见[验收服务管理](development.md#验收服务管理)。

页面启动不会自动连接打印机。主页面支持中文 → 英文，以及英文 → 中文核对；纸上始终只有英文和音标。没有打印机时可以使用翻译、预览和 AI 对话。Web 服务只监听 Mac 本机，手机不能通过这个地址访问；iPhone 使用[独立 App](../ios/README.md)。

## 翻译与音标

Mac Web 的通用翻译使用百度通用文本翻译。先在自己的百度翻译开放平台账号开通对应服务，再创建仅供本机使用的 `.local/baidu-translation.json`：

```json
{
  "appId": "",
  "secretKey": ""
}
```

在空值处填写自己的 APP ID 和密钥；使用 `appId`、`secretKey` 字段，普通 API Key 不替代它们。不要覆盖已有配置。创建目录与限制权限的命令：

```sh
mkdir -p .local
chmod 700 .local
# 在本地编辑器中创建或编辑上述文件后：
chmod 600 .local/baidu-translation.json
```

非内置词在停止输入约 1.5 秒后发起请求。翻译失败时可重试，不会静默切换到其他服务。iOS 当前使用 MyMemory，不读取或打包 Mac 的百度凭证；两端结果可能不同。

主页面的音标由本地 CMU 词典生成美式宽式 IPA。词组仅有一对外层斜杠，词间用一个空格分隔；缺少任一词的发音时阻止打印，需改正拼写或换词。常用词的多个候选需手动选择，单个候选自动选中。英译中的中文只作核对，不进入打印内容。

在标签设置中修改英文时，旧音标立即清空，重新查词完成前不能打印。也可手动校对当前英文的音标；查词的迟到结果不会覆盖手动输入。

## AI 助手

在“设置 → 大模型”填写 API URL、API Key 和模型 ID，保存后从底部中央入口进入聊天。支持文字、按住说话和选择一张照片；语音转成草稿，照片有预览，都需要再点击发送。

- 接口必须兼容 Anthropic Messages，使用 `x-api-key`；仅支持 OpenAI Chat Completions 的端点不能直接使用。
- API URL 可填 HTTPS 根地址、以 `/v1` 结尾的地址，或完整 `/v1/messages` 地址。本机模拟接口允许 HTTP；地址不接受账号、查询参数或片段。
- 已保存 Key 后留空表示保留；更换 API URL 必须重新填写 Key。模型 ID 按服务商支持项填写。
- 流式回复支持 Markdown、停止、重试和多轮上下文。打印卡片依赖模型支持流式工具调用；照片需要模型支持图片。
- `glm-5.3-flash` 可设置 `low / high / max` 思考强度，默认 `low`；其他模型不附加这个参数。

模型会结合物品描述或照片帮助选词，必要时显示候选按钮。明确用于标签的选项可以直接生成待确认卡片。**选择英文、生成卡片都不会出纸；只有点击打印按钮才操作设备。** 模型音标优先由完整本地词典结果替换，词典缺词时可能保留模型提供的音标，仍需人工核对。

单次回复最多 2048 输出 tokens，单段对话最多 20 轮、8 张照片，达到限制后新建对话。照片一次一张，原图最多 15 MiB，发送前缩放并重编码；语音可用性取决于系统、浏览器及麦克风权限。朗读使用英文语音合成，不逐个读 IPA 符号。

## 连接自己的 P0

目前设备检查针对德佟 P0，要求 203 dpi、96 点打印头。其他型号未验证。Mac 实物打印还需要 Swift 开发环境和蓝牙权限；先让打印机开机，并断开手机微打、iOS App 或其他客户端的连接。

Mac 必须配置自己的 CoreBluetooth UUID。它不是机身序列号，也不能直接使用 iPhone 的 peripheral ID。可使用仓库探测程序获取：

```sh
mkdir -p .local/bin
swiftc printer/probe.swift -o .local/bin/p0-probe
.local/bin/p0-probe
```

探测程序会扫描名称含 P0 的设备，连接首个匹配项、查询蓝牙服务并断开，**不打印纸张**；因此也不能与其他客户端同时占用设备。附近有多台 P0 时先只开启目标设备。记录输出 `Found printer: ... UUID` 中的 UUID，随后选一种配置方式：

- 创建 `.local/printer-device-id`，文件只写刚查到的 Mac UUID，无引号、无变量名。
- 或在启动服务的同一终端设置环境变量（替换占位值）：

  ```sh
  export P0_DEVICE_ID='YOUR_MAC_P0_UUID'
  ./scripts/preview.sh
  ```

环境变量优先于文件。若服务已经启动，需要在没有打印任务时停止自己的服务，再带配置重启。iOS 自动按 P0 名称发现设备并记录手机自己的标识，无需配置 Mac UUID。

## 打印与拆分

在“设置 → 标签”连接设备，按所用纸张设置宽高、字号和边距，查看预览；回到打印页输入并确认英文和音标，再点击打印。未连接时打印操作也会尝试连接。

默认标签为 30 × 12 mm，支持宽 10–100 mm、高 6–12 mm，步进 0.5 mm；当前两行居中、无边框。设备协议使用 203 dpi、90° 和 3 mm 间隔纸设置，浓度与速度沿用设备默认。软件范围不等同于所有纸张均已实测。

长词组按完整单词自动拆为多张，保留连字符复合词；按钮显示“拆分打印(0/N)”。一次点击授权当前整批串行打印，上一张确认完成后才继续，进度更新为 X/N。单个词仍放不下时需减小字号。主页面与 AI 卡片均支持拆分。

- “已打印”表示收到设备完成回执；“已发送，请查看出纸”只表示数据写入成功。纸面内容、排版仍需自己检查。
- 失败或结果不明确时立即停下，先检查是否已出纸；不会自动补打或恢复未完成批次。
- AI 卡片确认后永久锁定，历史恢复保留状态。需要重印时重新生成卡片；不要通过删除任务记录绕过防重。

独立命令行诊断使用固定旧模板，不读取网页设置。先断开网页及手机连接，再执行；`print` 会真实打印一张，只在明确需要试打时使用：

```sh
cd printer
./run.sh status
./run.sh preview 'hello' 'həˈloʊ'
# 真实出纸：
./run.sh print 'hello' 'həˈloʊ'
```

## 数据保存与隐私

| 数据 | Mac Web | iOS |
| --- | --- | --- |
| 模型配置 | `.local/model-config.json`，0600，明文文件 | 手机 Keychain |
| 翻译凭证 | `.local/baidu-translation.json`，由使用者设置 0600 | 不使用 Mac 凭证 |
| 对话、照片、草稿、卡片状态 | 当前浏览器 IndexedDB | App 的 Application Support 目录 |
| 打印防重记录 | `.local/print-jobs/` | App 沙盒 |

网页与手机历史不互相同步。正常覆盖安装保留 iOS 历史，卸载会删除；清除网站数据会删除网页历史。历史不会按 10 条自动淘汰，可以在历史列表逐条删除。iOS 单份历史快照最多 64 MiB，Web 容量受浏览器存储配额限制；读取或保存失败会明确报错，不会静默清空旧记录。

多个网页标签同时使用时，旧页面不能覆盖另一页更新的记录。遇到“聊天记录已在其他标签页更新”时，先复制需要保留的输入，再重新打开此页。同一张 AI 卡片的单张或整批打印只允许一个页面确认；重新打开、删除对话或旧快照回写不会解除已保存的消费标记。

通用翻译输入会发送给相应翻译服务；聊天、上下文及已发送照片会发送给配置的模型服务。语音可能依赖系统或浏览器的在线识别服务，原始音频不发送给聊天模型。本地保存不代表完全离线。

`.local/` 已被 Git 忽略，配置接口不返回 Key，静态服务仅提供 `web/` 资源。诊断不记录用户内容或密钥，也不自动上传；反馈问题前仍需检查截图、附件中是否含个人内容。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 页面打不开或保存配置失败 | 确认服务和 10290 端口仍在运行；保留表单输入，先恢复服务，不急着刷新 |
| 百度翻译配置不可用 | 检查文件路径、字段名、权限及对应服务开通状态 |
| 模型报 401 / 404 / 429 | 分别检查 Key、接口与模型 ID、服务额度或限流 |
| 连接不到 P0 | 检查电源、蓝牙权限、Mac UUID，以及是否被其他客户端连接 |
| 缺少音标或词组无法拆分 | 检查完整拼写，换用词典已有词；整词过长时减小字号 |
| 打印结果未确认 | 先看实际出纸，不连续点击重试；必要时按[诊断说明](development.md#诊断与-ios-符号)排查 |
