词签 HTML 交互预演
入口：http://127.0.0.1:10290/

打印：输入中文，停止输入约 650ms 后自动在线获取英文，然后从本地 CMU 发音词典转换为美式宽式音标。校验通过后可点击“打印”实际打印一张。新输入使旧请求失效，避免旧结果覆盖新内容。修改中文会清空旧结果，避免打印错内容。
设置：分为“标签”和“大模型”。标签固定上下两行、居中、30×12mm，支持预览内容、字号、可打印边框、四边边距调整，参数保存在本机浏览器。较短屏幕隐藏预览画布，保留编辑控件。
自定义打印：主打印按钮上方入口。弹窗里只填英文，自动从本地词典生成完整美式宽式音标；可复制 Fridge 后直接打印，无需手敲音标。未知词或内容超长会阻止打印；底部左打印、右取消，清空在英文与音标标题右侧；标签仍是上英文、下音标。
AI 助手：底部中央圆形入口。先在设置中填写 URL、API Key、模型 ID 并保存；支持 Anthropic Messages SSE 流式多轮聊天、停止、重试、新对话；回复的 Markdown 经安全清洗后呈现，宽表格可在自身区域左右滑动。中断时保留已收到的内容，重试替换未完成回复。消息发送给配置的模型服务；刷新清空对话。Key 由本机服务保存在 .local/model-config.json（0600，Git 忽略，不回传页面）。更换 URL 时重新填写 Key。

实测：390×844、390×664 下页面无纵向滚动，标题、按钮、导航、卡片 padding 一致；真实中文翻译、音标生成、连接/断开/重连，以及一张 hello 标签的设备完成回执通过。尚未用 iPhone 真机验证软键盘与安全区域，本次纸面效果待用户确认。
设备连接和打印已通过本机服务接入 Mac CoreBluetooth。开机并断开微打后，在设置中连接；打印前会检查尺寸、设备状态和缓存，设置里的字号、边距、边框及内容同步到实际标签。每次一张，错误不自动补打。只有设备确认完成才显示“已打印”，写入成功但未确认完成时显示“已发送”。结果不明时先检查是否出纸。
翻译需要网络，会将输入内容发送至 MyMemory。免费服务可能限流、超时或给出不准确结果；词典外内容会提示检查拼写，并拦截不完整音标。词组音标按单词拼接，不处理语流中的连读、弱读；宽式音标转换不等于专业校订的词典排版。

预览服务使用当前工作区 Node.js 22+，执行 node scripts/acceptance.mjs up，通过独立 tmux 会话后台运行；status 检查状态，down 停止。监听 127.0.0.1:10290，不依赖 Docker 或数据库。手机无法用 localhost 访问这台 Mac；当前链接供电脑预演。GET /api/health 用于核对服务工作区。

朗读：“英文与音标”标题右侧按钮使用设备的英文语音合成，朗读对应英文文本；点击“停止”可中止，修改内容也会停止。默认 en-US、语速 0.85。此功能不是逐个读出 IPA 符号，也不保证与词典音标的口音完全一致。音色与可用性取决于浏览器和操作系统。
